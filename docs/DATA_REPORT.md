## 3. Интерпретация (гипотезы, не факты)

* Значения по всей видимости — температура DTS в °C: на это указывают `dts_id`, диапазон и плавные суточные
  изменения. Организатор этого не подтверждал. Температурные и виброакустические данные не смешивались:
  виброакустических признаков в файлах не обнаружено.
* Шаг x 0.1015 и 0.2538 похож на метры (длина волокна 430–1190 м). В 5.csv x — целые числа с шагом 1.0,
  то есть, вероятно, индекс точки. Значимых точек там 1689 — ровно столько же, сколько в профиле канала 2
  прибора cd477c43 (3.csv). Возможно, это то же волокно, снятое в режиме «mapping» с шагом 10 с.
  **Это не подтверждено**, поэтому единицы x для 5.csv в интерфейсе подписаны «индекс точки».
* В 5.csv видны короткие локальные нагревы, перемещающиеся вдоль волокна. Это похоже на сеанс привязки
  трассы (mapping), но без подтверждения такая трактовка остаётся гипотезой.
* В 1.csv весь профиль периодически смещается как единое целое (общий сдвиг кадра), а горячие участки
  ступенчато включаются и выключаются. Поэтому в нормализацию добавлено вычитание общего сдвига кадра.
* Соответствия «прибор/канал → кабель» в данных нет, поэтому `cable_id` везде пуст.

## 4. Решения, принятые по EDA

| решение | причина |
|---|---|
| Один источник = файл + прибор + канал | Источники различаются шагом x, частотой опроса и шумом; объединять их без проверки нельзя. |
| Общая сетка x = самый длинный профиль файла | Короткие профили — префиксы этой сетки (проверяется; при несовпадении — интерполяция с отметкой в отчёте). |
| Бины ≈ 1 ед. x (10 точек в 1.csv, 4 точки в остальных) | Соседние точки коррелированы, объём сокращается в 4–10 раз. |
| Новый сегмент при разрыве > max(5 × шаг, 15 мин) | Из-за смешанного режима опроса в 1.csv порог «5 × шаг» сам по себе давал 116 ложных сегментов. |
| Хронологическое разбиение 60/20/20 внутри источника | Соседние окна сильно коррелированы, поэтому случайное разбиение недопустимо. |
| Пороги A и C — 6σ шума, а не квантиль | В validation 1.csv идут крупные реальные изменения: квантиль 99.8 % дал бы порог 31σ. |
